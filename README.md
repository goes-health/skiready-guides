# SkiReady Guides — by GOES Health

Family ski-trip cold safety: frostbite, hypothermia, and wind-chill cutoffs for kids. Each resort page shows a live National Weather Service wind chill.

Live at https://skiready.goes.health/

This repository is the published static site. Founded by wilderness medicine doctors.

GOES provides guidance and is not a substitute for professional medical care. If you think you have a medical emergency, call 911.
